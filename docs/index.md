# Pat Pat Docs

Pat Pat 是一个围绕 Git worktree 的 VS Code 扩展，用于 orchestrate inte-pat / feat-pat / session 工作流。

## 快速上手

- 运行 `Bootstrap inte-pat` 初始化主干分支（命名为 `pat-pat/<inte>/__inte__`）。
- 使用 `New feat-pat` 从主干 fork 出子分支并生成对应 worktree。
- 在 Sessions 视图中点击 `Run session` 启动某个 session 的终端组，可通过 `Edit start command` 配置启动脚本。
- `Configure feat-pat` 用于批量调整 feat-pat 的图标、配色及 session 配置。

更多信息见 [Inte-pat / Feat-pat / Session 结构](structure.html)。
